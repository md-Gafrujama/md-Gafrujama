## 🔧 Git & GitHub Workflow

<div align="center">
  <img src="https://media.giphy.com/media/kH6CqYiquZawmU1HI6/giphy.gif" width="300" alt="Git" />
</div>

<details>
<summary><b>🚀 Getting Started & Configuration</b></summary>

```bash
git config --global user.name "Your Name"
git config --global user.email "your.email@example.com"
git config --list

git init
git clone https://github.com/username/repository.git
git clone https://github.com/username/repository.git my-folder-name
```

</details>

<details>
<summary><b>📝 Basic Workflow</b></summary>

```bash
git status
git add .                    # Add all files
git add filename.js          # Add specific file
git add src/                 # Add entire directory

git commit -m "Your commit message"
git commit -am "Add and commit tracked files"

git log
git log --oneline
git log --graph --oneline
git log --all --graph --decorate

git diff                     # Unstaged changes
git diff --staged            # Staged changes
git diff HEAD                # All changes
```

</details>

<details>
<summary><b>🌿 Branching & Merging</b></summary>

```bash
git branch                    # List branches
git branch branch-name        # Create branch
git branch -d branch-name     # Delete branch
git branch -D branch-name     # Force delete

git checkout branch-name
git checkout -b new-branch
git switch branch-name
git switch -c new-branch

git merge branch-name
git merge --no-ff branch-name

git rebase main
git rebase -i HEAD~3
```

</details>

<details>
<summary><b>🔄 Remote Operations</b></summary>

```bash
git remote -v
git remote add origin URL
git remote remove origin
git remote set-url origin URL

git push origin main
git push -u origin main
git push --all
git push --tags

git pull origin main
git fetch origin
git fetch --all
```

</details>

<details>
<summary><b>🔍 Advanced Commands</b></summary>

```bash
# Undo changes
git restore filename.js
git restore --staged file.js
git reset HEAD~1             # Undo last commit (keep changes)
git reset --hard HEAD~1      # Undo last commit (discard changes)
git revert HEAD              # New commit that undoes changes

# Stash
git stash
git stash save "message"
git stash list
git stash pop
git stash apply
git stash drop

# Tags
git tag
git tag v1.0.0
git tag -a v1.0.0 -m "Release"
git push origin v1.0.0

# Clean up
git clean -n                 # Preview
git clean -f
git clean -fd
```

</details>

<details>
<summary><b>🔐 GitHub CLI & Fork Workflow</b></summary>

```bash
gh auth login
gh repo clone user/repo
gh repo create
gh repo view
gh issue list
gh pr create
gh pr list
gh pr checkout 123

# Fork and contribute
git clone https://github.com/YOUR-USERNAME/repo.git
cd repo
git remote add upstream https://github.com/ORIGINAL-USER/repo.git
git checkout -b feature-name
git add .
git commit -m "Add new feature"
git push origin feature-name
# Open a Pull Request on GitHub

# Keep fork updated
git fetch upstream
git merge upstream/main
git push origin main
```

</details>

<details>
<summary><b>📋 Commit Convention & Cheat Sheet</b></summary>

```bash
# Format: <type>(<scope>): <subject>
feat:      # New feature
fix:       # Bug fix
docs:      # Documentation
style:     # Formatting only
refactor:  # Code refactoring
test:      # Tests
chore:     # Maintenance

git commit -m "feat(auth): add user login functionality"
git commit -m "fix(api): resolve CORS issue"
git commit -m "docs(readme): update installation guide"
```

<div align="center">

| ⏰ Time | 🔄 Action | 💻 Command |
|:------:|:--------:|:----------:|
| **Morning** | Check status | `git status` |
| **Before work** | Pull latest | `git pull origin main` |
| **During work** | Stage changes | `git add .` |
| **After feature** | Commit | `git commit -m "feat: description"` |
| **Before push** | Check diff | `git diff HEAD` |
| **End of day** | Push changes | `git push origin main` |

</div>

</details>
