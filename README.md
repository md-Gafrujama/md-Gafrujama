<details>
<summary><b>🔧 Git Quick Reference</b></summary>

```bash
git status                    # check changes
git add .                     # stage all
git commit -m "feat: message" # commit
git push origin main          # push
git pull origin main          # pull latest
git checkout -b feature-name  # new branch
git merge feature-name        # merge branch
git stash / git stash pop     # save and restore work in progress
git log --oneline --graph     # visual history
```

**Commit convention:** `feat` · `fix` · `docs` · `style` · `refactor` · `test` · `chore`
e.g. `feat(auth): add user login functionality`

**Fork workflow:** fork → clone → `git remote add upstream <url>` → branch → commit → push → open PR → `git fetch upstream && git merge upstream/main`

</details>
